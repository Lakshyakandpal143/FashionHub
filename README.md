# FashionHub – Full-Stack E-Commerce Platform

FashionHub is a full-stack e-commerce web application designed to provide users with a modern online shopping experience. The project includes user authentication, profile management, product browsing, and a responsive frontend.

## 🚀 Features

- User registration and login
- User profile management
- Product browsing
- E-commerce shopping interface
- Responsive design
- Frontend and backend integration
- RESTful API architecture
- MongoDB database integration

## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

- npm
